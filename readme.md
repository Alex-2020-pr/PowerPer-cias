# Power Perícias - Site Institucional

Site profissional para a Power Perícias, especializada em perícia médica online para DPVAT, INSS e Seguros Diversos.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3 (com variáveis e design responsivo)
- JavaScript (menu mobile, formulário e integração WhatsApp)
- Font Awesome (ícones)
- Google Fonts (via sistema)
